Challenges
VLAN Trunk MisconfigurationDefault trunk allowed all VLANs — had to whitelist only required ones to enforce segmentation.

AD & Enterprise SecurityBuilding from scratch revealed how much of Windows security sits on AD — GPOs, Kerberos, delegation.
Detection EngineeringWriting SIEM alert rules taught how defenders think and how attackers stay below detection thresholds.

01Multi-threaded scanning engine — AsyncIO-based concurrent port scanner across the full 65,535 port range.

03Structured JSON output — results parsed into actionable format for pipeline integration, unlike raw nmap output.
// Code
packetpulse.py — Python
async def scan_port(host, port):
  try:
    reader, writer = await asyncio.open_connection(host, port)
    banner = await asyncio.wait_for(reader.read(1024), timeout=2)
    return { "port": port, "status": "open", "banner": banner }
  except: return None
// Challenges & Learnings
Challenges
Rate Limiting & TimeoutsScanning 65,535 ports naively caused mass timeouts — tuned concurrency limits and per-host timeout values.
Learnings
Async I/O for Network ToolsAsyncIO dramatically outperforms threaded scanning — learned how to structure concurrent network I/O.
