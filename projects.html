02Deployed Active Directory domain — Windows Server DC, OUs, GPOs for password policy, desktop lockdowns, software restrictions.

// Challenges & Learnings

Challenges
VLAN Trunk MisconfigurationDefault trunk allowed all VLANs — had to whitelist only required ones per port to enforce proper segmentation.
AD DNS IssuesDomain joins failing because client DNS pointed to ISP, not the DC. Fixing DNS forwarding resolved it.
SIEM Log NoiseRaw Windows event forwarding generated thousands of low-value events per hour — required significant filter tuning.
Learnings
L2 Networking in PracticeConfiguring VLANs and STP by hand gave concrete understanding far beyond what Packet Tracer simulates.
How AD Underpins Enterprise SecurityBuilding from scratch revealed how much of Windows security sits on AD — GPOs, Kerberos, delegation.
Detection EngineeringWriting SIEM alert rules for real attack patterns taught how defenders think and how attackers stay below thresholds.

PacketPulse

A multi-threaded Python engine for deep network enumeration. Automates live host discovery and service fingerprinting across all 65,535 ports — built after nmap's output proved too difficult to parse programmatically.

Python Scapy AsyncIO Nmap Engine

// What I Built

01Multi-threaded scanning engine — AsyncIO-based concurrent port scanner across full 65,535 port range.
02Service fingerprinting — banner grabbing and protocol detection to identify running services.
03Structured JSON output — results parsed into actionable format for pipeline integration, unlike raw nmap output.

// Code

packetpulse.py — Python
async def scan_port(host, port):
  try:
    reader, writer = await asyncio.open_connection(host, port)
    banner = await asyncio.wait_for(reader.read(1024), timeout=2)
    return { "port": port, "status": "open", "banner": banner }
  except: return None

// Challenges & Learnings

Challenges
Rate Limiting & TimeoutsScanning all 65,535 ports naively caused timeouts. Had to tune concurrency limits and connection timeouts per host.
Learnings
Async I/O for Network ToolsAsyncIO dramatically outperforms threaded scanning — learned how to structure concurrent network I/O properly.
